# 貓玩聚代儲

延續既有 HTML、CSS、JavaScript 與 Supabase 的營運管理網站，包含訂單、商品方案、續約、座位、廣告、記事及財務管理。

正式由 GitHub Pages 的 main 分支根目錄發布；推送 main 會影響營運網站。資料庫增量來源及套用方式見 [database/README.md](database/README.md)。正式更新前須完成私人備份與恢復驗證，先成功更新結構，再更新前端。

`runtime-config.js` 只放公開部署設定；原有瀏覽器用 anon 設定保留於原位置。不得加入 service_role、資料庫密碼、登入 Token、客戶匯出或私人備份。所有財務寫入由驗證擁有者與店舖的 RPC 處理，不能僅依前端選單當作授權。

財務畫面是營運管理試算，收付款與服務期間收入分開；不是正式會計／稅務申報工具。開始使用時先設定財務起算日、銀行及營業卡款期初。原歷史訂單保留，不從缺失資料猜填銀行金流。

本機虛構資料、測試帳戶及離線預覽不隨正式版本發布。這個工作目錄目前為待上線候選版本，README 本身不代表已部署。
